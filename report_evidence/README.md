# Report Evidence Pack

Use this folder to keep all proof material for your final report.

## 1) Screenshots

Save screenshots in the matching folder:

- `screenshots/01-login-register/`
- `screenshots/02-customer-booking/`
- `screenshots/03-admin-driver-assignment/`
- `screenshots/04-driver-trips/`
- `screenshots/05-validation-errors/`

Use `screenshots/SHOT_LIST.md` as your capture checklist.

## 2) Testing Evidence

- Fill test cases: `testing/test-cases-template.md`
- Fill execution notes: `testing/test-execution-log.md`
- Keep unit test run output: `testing/unit-test-output.txt`

## 3) Submission Checklist

- Complete `checklist/final-submission-checklist.md` before final upload.
