# Final Submission Checklist

## Code and App

- [ ] App runs with: `uv run -m app.main`
- [ ] Customer can register (name, address, phone, email)
- [ ] Customer can create booking (pickup, drop-off, date, time)
- [ ] Customer can edit/cancel pending bookings
- [ ] Admin can view all bookings
- [ ] Admin can assign driver to booking
- [ ] Driver overlap prevention works
- [ ] Driver can view assigned trips

## Testing

- [ ] `uv run -m unittest discover -s tests -v` passes
- [ ] `report_evidence/testing/test-cases-template.md` filled
- [ ] `report_evidence/testing/test-execution-log.md` filled
- [ ] Screenshot evidence linked in each test case

## Report and Delivery

- [ ] Required report sections completed in correct order
- [ ] UML diagrams and DB design match implementation
- [ ] UI screenshots added
- [ ] Zip file includes source code + tests + diagrams
- [ ] Video presentation prepared and uploaded
